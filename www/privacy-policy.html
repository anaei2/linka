Política de Privacidade — Linka

Última atualização: 6 de outubro de 2026.

O Linka é um aplicativo de mensagens. Esta política explica, de forma simples, como os dados necessários para o funcionamento do serviço são tratados.

Dados usados pelo Linka

O serviço pode armazenar dados fornecidos pelo usuário, como nome, identificador, contatos, mensagens, arquivos, status e informações necessárias para chamadas e notificações.

Mensagens e arquivos

As mensagens e arquivos são usados para entregar as conversas e os recursos escolhidos pelo usuário. O Linka não vende o conteúdo das conversas para publicidade.

Notificações

Quando autorizadas, as notificações podem usar o Firebase Cloud Messaging para entregar avisos de novas mensagens e chamadas.

Segurança

São aplicadas medidas técnicas para proteger os dados e as contas, mas nenhum serviço conectado à internet pode garantir segurança absoluta.

Exclusão de dados

Para solicitar ajuda com exclusão ou correção de dados da conta, entre em contato com o responsável pelo serviço Linka.

Alterações

Esta política poderá ser atualizada quando os recursos do Linka mudarem.
